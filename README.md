# EduGrowth Pro - Coaching Institute Website Demo

A premium SaaS/business-style React website demo for coaching institutes.

## Features
- Modern landing page design
- Course showcase
- Admissions-focused copy
- WhatsApp enquiry button
- Results/statistics section
- Testimonials section
- Mobile responsive design
- Ready for Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in terminal.

## Build

```bash
npm run build
```

## Deploy on Vercel
1. Push this folder to GitHub.
2. Go to https://vercel.com
3. Import the repo.
4. Click Deploy.

## Customize for client
Edit `src/main.jsx`:
- Institute name
- Phone number
- WhatsApp number
- Courses
- Location
- Testimonials
- Stats
